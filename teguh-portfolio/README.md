# Teguh Prasetyo — Personal Portfolio v2

Portfolio PHP modern dengan Bootstrap 5 dan JavaScript.

## Jalankan di XAMPP
1. Extract folder `teguh-portfolio-v2`.
2. Pindahkan ke `C:\xampp\htdocs\teguh-portfolio-v2`.
3. Jalankan Apache di XAMPP.
4. Buka `http://localhost/teguh-portfolio-v2/`.

## CV
Jika ingin tombol Download CV aktif, letakkan file CV Anda di:
`assets/CV-Teguh-Prasetyo.pdf`

Jika nama file berbeda, ubah href tombol Download CV di `index.php`.

## Catatan project
Portfolio hanya menampilkan ringkasan project. Source code, database, credentials, dan data perusahaan tidak dimasukkan.

## Online hosting
PHP dapat dijalankan di hosting yang mendukung PHP. GitHub Pages tidak menjalankan PHP server-side.
